# Verification record: 0.4.0 (compact conventions)

What was run, for real, before 0.4.0 was proposed for release. 0.4.0 adds
`GARDENER_CONVENTIONS_SUBDIR` / `align --conventions-subdir`, which makes a
subdirectory of the conventions repo the conventions root. The primary goal
was confirming that `align` without it behaves as in 0.3.0, and that `align`
with it reads only the subdirectory.

- **Code verified:** branch `feature/conventions-subdir` at `f68aaa2`. The only
  later change is the version bump (`0.3.0` → `0.4.0`) and this record.
- **Date:** 2026-10-10.
- **Environment:** WSL2 (Linux 5.10), Python 3.11.15, Claude Code CLI 2.1.293.
- **Target repo:** the public `Stephenson-Software/multiplyTwoNumbers`, which
  is in the operator's garden.
- **Isolation:** as in [0.3.0](0.3.0.md), every run used a fresh scratch
  `GARDENER_STATE_DIR` and `GARDENER_CACHE_DIR`, with usage reporting off and
  no hub, so nothing reached the real history, alerts or hub. The
  conventions repos used are the operator's own and are not named here.

## Automated tests

`PYTHONPATH=. python -m unittest discover -s tests` ran **1108 tests, OK** on
both Python 3.10.20 and 3.11.15. That is 8 more than 0.3.0's 1100.

The new tests check that:

- the subdirectory becomes the conventions root;
- an empty value means the repo root;
- the subdirectory must carry the full required layout;
- `..`, absolute paths, `.` and escapes are refused, as is a missing
  directory (an error, not a fallback);
- the flag wins over the environment variable;
- `cmd_align` passes the subdirectory into the checkout, the prompt and the
  agent's readable directories.

`TestUsageDocumentsEveryVisibleFlag` caught the new flag before it was
documented.

## 3. With Orket's governed harness (secondary)

The subdirectory was also handed to Orket 0.8.1's
`examples/gardener_harness` through the `command` harness. That
harness counts every tracked file of the conventions directory against a
64 KiB budget.

- **Full conventions repo (about 92 KB of docs):** refused before any model
  call ("selected snapshot content exceeds the byte budget").
- **`compact/` (21.5 KB):** admitted. With Ollama on CPU and a 16k context,
  the run reached the model in both cases:
  - `llama3.2:3b` returned a report citing a source it was never given, and
    Orket's `structured_report.v1` refused it;
  - `qwen2.5:7b` exceeded the harness's fixed 8,192-token input profile
    (McElyea/Orket#5).

So the setting does what it is for: the snapshot becomes admissible. No
report was delivered on that hardware for model reasons. Those are
recorded upstream, not here.
