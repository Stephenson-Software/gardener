# Verification record: 0.4.6 (`--implement` can no longer merge)

`align --implement` granted `Bash(gh pr *)`. That pattern also matches
`gh pr merge`, so "Do not merge the PR" rested on the prompt alone. This
was known: it was point 4 of `dispatch.py`'s module docstring and was noted
in SAFETY.md as out of scope. `tend` already listed its `gh pr` verbs.
0.4.6 gives `--implement` the same treatment: `IMPLEMENT_PR_TOOLS` lists
create, edit, view, list, diff and checks.

- **Code verified:** branch `fix/implement-pr-verbs`.
- **Date:** 2026-10-11.
- **Environment:** WSL2 (Linux 5.10), Python 3.11.15 and 3.10.20, Claude
  Code with the operator's subscription.
